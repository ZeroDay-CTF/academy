# Конспекты занятий

Здесь размещайте заметки по проведённым занятиям. Для новых материалов используйте `Templates/Урок.md`.

Рекомендуемое имя: `YYYY-MM-DD — Краткая тема.md`.

После занятия зафиксируйте:
- какие цели достигнуты;
- какие ошибки встречались у группы;
- какие материалы нужно улучшить;
- что повторить на следующем занятии.
