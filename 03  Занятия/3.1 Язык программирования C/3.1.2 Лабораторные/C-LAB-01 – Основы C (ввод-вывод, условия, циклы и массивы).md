## Цель работы

На практике закрепить основы языка C: написать и собрать консольные
программы, обработать пользовательский ввод, использовать условия и
циклы, а также выполнить обработку массива фиксированного размера.

## Что нужно знать перед началом

-   Переменные и основные типы: `int`, `double`.
-   `printf` и `scanf`.
-   Условия `if`, `else if`, `else`.
-   Циклы `for` и `while`.
-   Функции и массивы.
-   Разницу между `=` и `==`, а также между целочисленным и вещественным
    делением.

## Подготовка окружения

1.  Создайте отдельную папку `C-LAB-01`.
2.  Создавайте для каждого задания отдельный файл `.c`, например
    `task1.c`.
3.  Убедитесь, что программа компилируется и запускается.
4.  Для каждого задания сохраните исходный код и результаты
    тестирования.

Если используется GCC или Clang:

``` bash
gcc task1.c -Wall -Wextra -std=c11 -o task1
./task1
```

В Windows при наличии GCC в `PATH`:

``` powershell
gcc task1.c -Wall -Wextra -std=c11 -o task1.exe
.\task1.exe
```

`-Wall -Wextra` включают полезные предупреждения компилятора.
Исправляйте предупреждения, а не игнорируйте их. В Visual Studio можно
создать консольный проект и добавить в него исходный файл C; убедитесь,
что файл компилируется именно как C.

## Правила выполнения

-   Не копируйте готовое решение целиком: сначала составьте алгоритм
    словами или псевдокодом.
-   Проверяйте результат на обычных, граничных и некорректных входных
    данных.
-   Проверяйте результат `scanf`: он должен считать ожидаемое количество
    значений.
-   Не обращайтесь к элементам массива за пределами его размера.
-   Используйте понятные имена переменных и форматируйте код отступами.
-   Если задание не задаёт иной формат, выводите результат с поясняющей
    подписью.

## Задание 1. Первая программа и арифметика

**Время:** 15 минут\
**Файл:** `task1.c`

### Часть A --- базовая

Напишите программу, которая выводит:

1.  Ваш учебный псевдоним.
2.  Название языка программирования.
3.  Результат выражения `15 + 27`.

Пример формата вывода:

``` text
Student: learner
Language: C
15 + 27 = 42
```

Вместо `learner` укажите свой псевдоним.

### Часть B --- основная

Считайте два целых числа `a` и `b`. Выведите:

-   сумму `a + b`;
-   разность `a - b`;
-   произведение `a * b`;
-   частное `a / b`, если `b` не равно нулю.

Для частного получите вещественный результат, а не целочисленный. Если
второе число равно нулю, выведите сообщение об ошибке вместо деления.

Если ввод не содержит двух целых чисел, программа должна сообщить о
некорректном вводе и завершиться без вычислений.

### Проверки

  Ввод      Что проверить
  --------- -----------------------------------------------------------
  `7 2`     Сумма `9`, разность `5`, произведение `14`, частное `3.5`
  `8 0`     Программа не делит на ноль
  `-4 2`    Корректная работа с отрицательным числом
  `abc 2`   Обработка некорректного ввода

## Задание 2. Условия и классификация

**Время:** 20 минут\
**Файл:** `task2.c`

### Часть A --- знак и чётность

Считайте целое число. Выведите его знак:

-   `Positive`, если число больше нуля;
-   `Negative`, если число меньше нуля;
-   `Zero`, если число равно нулю.

Затем отдельно определите чётность и выведите `Even` или `Odd`.

Примеры ожидаемого поведения:

  Ввод   Вывод
  ------ --------------------------
  `0`    `Zero`, затем `Even`
  `-4`   `Negative`, затем `Even`
  `7`    `Positive`, затем `Odd`

### Часть B --- максимум из трёх

Считайте три целых числа и выведите наибольшее из них. Не используйте
массивы или готовые функции поиска максимума: решите задачу условиями.

Проверьте в том числе случаи, когда:

-   первое число самое большое;
-   третье число самое большое;
-   два или три числа равны;
-   все числа отрицательные.

### Часть C --- классификация баллов

Считайте целое число `score` от 0 до 100 и выведите категорию:

-   90--100 --- `Excellent`;
-   70--89 --- `Good`;
-   50--69 --- `Satisfactory`;
-   0--49 --- `Unsatisfactory`.

Если число меньше 0 или больше 100, выведите `Invalid score`.
Некорректный текстовый ввод также должен обрабатываться.

Обязательно протестируйте границы диапазонов: `49`, `50`, `69`, `70`,
`89`, `90`, а также `-1` и `101`.

## Задание 3. Числовые алгоритмы

**Время:** 20 минут\
**Файлы:** `task3a.c`, `task3b.c`

### Часть A --- сумма от 1 до N

Считайте положительное целое число `N` и вычислите сумму:

\[ 1 + 2 + 3 + `\ldots `{=tex}+ N \]

Требования:

-   используйте цикл `for`;
-   храните промежуточную сумму в отдельной переменной;
-   если `N` меньше 1 или ввод некорректен, выведите сообщение об
    ошибке;
-   для `N = 5` результат должен быть `15`.

Дополнительный вопрос: измените цикл так, чтобы он суммировал только
чётные числа от 1 до `N`.

### Часть B --- количество цифр

Считайте неотрицательное целое число и посчитайте количество его цифр.
Число `0` считается однозначным.

Примеры:

  Ввод       Результат
  -------- -----------
  `0`              `1`
  `7`              `1`
  `42`             `2`
  `1000`           `4`

Используйте цикл `do...while` или обоснуйте, как иначе вы обрабатываете
значение `0`. Не переводите число в строку для подсчёта цифр.

### Дополнительное задание --- факториал

Факториал числа `N` --- произведение чисел от 1 до `N`; по определению
`0! = 1`.

Напишите программу, которая вычисляет `N!` для `0 <= N <= 20`.
Отклоняйте значения вне этого диапазона и некорректный ввод. Выберите
тип, который позволяет хранить результат в указанном диапазоне.

Примеры: `0` → `1`, `5` → `120`.

## Задание 4. Обработка массива

**Время:** 15 минут\
**Файл:** `task4.c`

Дан массив:

``` c
int numbers[5] = {4, 8, 2, 9, 1};
```

### Часть A --- минимум и максимум

Пройдите по массиву циклом и найдите минимальный и максимальный
элементы. Не используйте готовые функции поиска.

Ожидаемый результат:

``` text
Min: 1
Max: 9
```

### Часть B --- статистика

Расширьте программу и вычислите:

-   сумму всех элементов;
-   среднее арифметическое;
-   количество чётных элементов.

Для среднего арифметического используйте вещественный тип, чтобы не
потерять дробную часть из-за целочисленного деления.

### Часть C --- ввод массива (дополнительно)

Измените программу так, чтобы пользователь вводил пять целых чисел.
Проверьте, что каждое значение успешно считано. Не изменяйте размер
массива во время выполнения и не обращайтесь к индексу `5`: допустимые
индексы этого массива --- от `0` до `4`.

## Задание 5. Функции (дополнительно)

**Файл:** `task5.c`

Вынесите вычисление суммы массива в функцию:

``` c
int sum_array(const int numbers[], int length);
```

Функция должна возвращать сумму первых `length` элементов. В `main`
вызовите её и выведите результат.

Условия:

-   функция не должна содержать `printf`;
-   размер массива передавайте отдельным аргументом;
-   не обращайтесь к элементам массива, если `length` не положителен;
-   объясните, почему при передаче массива в функцию нужно отдельно
    передавать его длину.

## Контрольные вопросы

1.  Чем отличаются `=` и `==`?
2.  Почему `7 / 2` при двух операндах типа `int` даёт `3`?
3.  Для чего в `scanf("%d", &a)` нужен оператор `&`?
4.  Что означает проверка `scanf(...) != 2`?
5.  В чём разница между `while` и `do...while`?
6.  Почему для массива из пяти элементов нельзя использовать индекс `5`?
7.  Зачем при вычислении среднего приводить сумму к `double`?
8.  Почему функция обработки массива обычно принимает длину отдельным
    аргументом?
