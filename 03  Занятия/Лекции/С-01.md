# Введение в C: от Python к системному программированию

## Теория

### 1. Зачем нужен C

C — компилируемый язык общего назначения, широко используемый в
системном программировании. На нём пишут компоненты операционных систем,
драйверы, встроенное ПО, системные утилиты, сетевые библиотеки и части
инструментов разработки.

Для специалиста по информационной безопасности C полезен не только как
язык разработки. Он помогает понимать представление данных в памяти,
вызовы функций, работу с адресами и причины ошибок, которые могут
приводить к уязвимостям.

#### C и Python

| Характеристика     | C                                               | Python                                                                                                   |
|:-------------------|:------------------------------------------------|:---------------------------------------------------------------------------------------------------------|
| Типизация          | Статическая                                     | Динамическая                                                                                             |
| Типичный запуск    | Компиляция и сборка исполняемой программы       | В распространённых реализациях исходный код превращается в байткод, который выполняет виртуальная машина |
| Переменные         | Тип указывается в объявлении                    | Имя может связываться с объектами разных типов                                                           |
| Массивы и списки   | Встроенный массив имеет фиксированный размер    | Список может динамически увеличиваться                                                                   |
| Управление памятью | Доступно больше низкоуровневого контроля        | Управление объектами в значительной мере автоматизировано                                                |
| Типичные задачи    | Системное ПО, библиотеки, встроенные устройства | Автоматизация, веб-разработка, анализ данных                                                             |

Важно: не стоит сводить различие к формуле «C быстрый, Python
медленный». Скорость зависит от конкретной задачи, реализации, библиотек
и способа использования языка.

Один алгоритм на двух языках:

**Python**

``` python
a = 10
b = 20
print(a + b)
```

**C**

``` c
#include <stdio.h>

int main(void) {
    int a = 10;
    int b = 20;

    printf("%d\n", a + b);
    return 0;
}
```

Алгоритм тот же, но C требует явно объявить типы переменных и
организовать программу через функцию `main`.

### 2. Как запускается программа на C

Обычный процесс сборки можно представить так:

1.  **Препроцессор** обрабатывает директивы, например `#include`.
2.  **Компилятор** анализирует исходный код и переводит его в
    низкоуровневое представление.
3.  **Ассемблер** может преобразовать ассемблерный текст в объектный
    файл.
4.  **Компоновщик** связывает объектные файлы и необходимые библиотеки.
5.  **Операционная система** загружает и запускает полученную программу.

Реальные инструменты могут объединять этапы, но ключевая идея остаётся
прежней: в обычном процессе разработки C сначала собирают, а затем
запускают.

#### Сборка из терминала

Если установлен GCC или Clang:

**Linux/macOS**

``` bash
gcc main.c -o main
./main
```

**Windows, если GCC доступен в `PATH`**

``` powershell
gcc main.c -o main.exe
.\main.exe
```

`main.c` — исходный файл, параметр `-o` задаёт имя результата.

#### Visual Studio и Visual Studio Code

**Visual Studio** — полноценная IDE со средствами сборки и отладки.
Проверьте, что файл с расширением `.c` компилируется именно как C:
шаблон консольного проекта может быть настроен на C++.

**Visual Studio Code** — редактор, а не компилятор. Нужно отдельно
установить и настроить GCC, Clang или MSVC. Расширение C/C++ добавляет
подсветку, подсказки и интеграцию с отладчиком, но само по себе не
заменяет компилятор.

#### Типы ошибок

- **Синтаксическая:** нарушены правила языка, например пропущена `;`.
- **Ошибка компоновки:** не найдена реализация функции или необходимый
  символ.
- **Ошибка выполнения:** программа аварийно завершается или ведёт себя
  некорректно во время работы.
- **Логическая:** программа запускается, но выдаёт неверный результат.

### 3. Структура программы и синтаксис

Первая программа:

``` c
#include <stdio.h>

int main(void) {
    printf("Hello, world!\n");
    return 0;
}
```

- `#include <stdio.h>` подключает объявления стандартных функций
  ввода-вывода, в том числе `printf` и `scanf`.
- `int main(void)` — главная функция обычной программы; `int` обозначает
  тип возвращаемого значения, `void` в списке параметров — отсутствие
  параметров.
- `{` и `}` задают блок кода.
- `printf` выводит текст, а `\n` означает переход на новую строку.
- `return 0;` обозначает успешное завершение программы.

В C большинство инструкций заканчивается точкой с запятой. В Python
границы блоков задаются отступами, а в C — фигурными скобками. Отступы в
C всё равно важны для читаемости.

``` c
int age = 18;
age = age + 1;
printf("%d\n", age);
```

### 4. Типы данных и переменные

В C тип переменной объявляется явно:

``` c
int age = 18;
double temperature = 21.5;
char letter = 'A';
float ratio = 0.5f;
long long population = 10000000000LL;
```

| Тип         | Назначение                                                                             |
|:------------|:---------------------------------------------------------------------------------------|
| `char`      | Объект размером в один байт; часто используется для символьных данных                  |
| `int`       | Целые числа                                                                            |
| `float`     | Числа с плавающей точкой                                                               |
| `double`    | Числа с плавающей точкой, обычно с большей точностью, чем `float`                      |
| `long long` | Целый тип с диапазоном не меньше стандартного минимального диапазона 64-битного целого |

Фактические размеры и диапазоны некоторых типов зависят от реализации.
При необходимости размер можно проверить через `sizeof`.

``` c
printf("int: %zu bytes\n", sizeof(int));
printf("double: %zu bytes\n", sizeof(double));
```

`sizeof` возвращает размер в байтах, а `%zu` используется для вывода
значения типа `size_t`.

#### Присваивание и сравнение

``` c
int x = 5;
x = x + 2;

if (x == 7) {
    printf("Seven\n");
}
```

- `=` — присваивание.
- `==` — сравнение на равенство.

Это разные операции. В C переменная типа `int` не может использоваться
как строковая переменная так, как это допускает динамическая типизация
Python.

#### Арифметика и деление

``` c
int a = 7;
int b = 2;

printf("%d\n", a + b); // 9
printf("%d\n", a - b); // 5
printf("%d\n", a * b); // 14
printf("%d\n", a / b); // 3
printf("%d\n", a % b); // 1
```

Если оба операнда целые, `/` выполняет целочисленное деление, а `%`
возвращает остаток.

Чтобы получить дробный результат:

``` c
double result = (double)a / b;
printf("%f\n", result);
```

Сравнение с Python:

``` python
print(7 / 2)   # 3.5
print(7 // 2)  # 3
print(7 % 2)   # 1
```

#### Ввод и вывод

``` c
#include <stdio.h>

int main(void) {
    int age;
    double height;

    printf("Enter age and height: ");

    if (scanf("%d %lf", &age, &height) != 2) {
        printf("Invalid input\n");
        return 1;
    }

    printf("Age: %d\n", age);
    printf("Height: %.2f\n", height);

    return 0;
}
```

`scanf` читает данные по форматной строке. Возвращаемое значение —
количество успешно считанных элементов. Его следует проверять, чтобы не
продолжать работу с некорректными данными.

`&age` передаёт адрес переменной, куда функция должна записать считанное
значение. Для числового ввода в MSVC можно использовать `scanf_s` с
соответствующими форматами. При чтении строк у `scanf_s` есть
дополнительные требования к размеру буфера.

Основные спецификаторы:

| Спецификатор | Применение                                                           |
|:-------------|:---------------------------------------------------------------------|
| `%d`         | `int`                                                                |
| `%c`         | символьное значение                                                  |
| `%f`         | `float` при чтении через `scanf`; `double` при выводе через `printf` |
| `%lf`        | `double` при чтении через `scanf`                                    |
| `%zu`        | `size_t`                                                             |

### 5. Условия и циклы

#### Условия

**Python**

``` python
if x > 0:
    print("Positive")
elif x < 0:
    print("Negative")
else:
    print("Zero")
```

**C**

``` c
if (x > 0) {
    printf("Positive\n");
} else if (x < 0) {
    printf("Negative\n");
} else {
    printf("Zero\n");
}
```

В C используется `else if`, а не `elif`. Целое значение `0` считается
ложным, ненулевое — истинным.

Логические операторы:

| C                    | Значение  |
|:---------------------|:----------|
| `&&`                 | И         |
| `||`                 | ИЛИ       |
| `!`                  | НЕ        |
| `==`                 | равно     |
| `!=`                 | не равно  |
| `<`, `>`, `<=`, `>=` | сравнения |

Пример проверки диапазона:

``` c
if (score >= 0 && score <= 100) {
    printf("Valid score\n");
}
```

`&&` и `||` используют короткое замыкание: правый операнд может не
вычисляться, если результат уже определён левым.

#### Цикл `for`

**Python**

``` python
for i in range(5):
    print(i)
```

**C**

``` c
for (int i = 0; i < 5; i++) {
    printf("%d\n", i);
}
```

Части `for`:

``` c
for (инициализация; условие; изменение) {
    // тело
}
```

Инициализация выполняется один раз; условие проверяется перед каждой
итерацией; изменение выполняется после тела. В примере выводятся числа
`0`, `1`, `2`, `3`, `4`.

#### Цикл `while`

``` c
int i = 0;

while (i < 5) {
    printf("%d\n", i);
    i++;
}
```

`while` проверяет условие до выполнения тела. В `do...while` проверка
выполняется после тела, поэтому оно выполнится хотя бы один раз:

``` c
int n = 0;

do {
    printf("%d\n", n);
    n++;
} while (n < 3);
```

Обратите внимание на точку с запятой после условия `while`.

#### Частые ошибки в циклах

- Неверная граница: `i <= 5` при обходе массива из пяти элементов
  приводит к выходу за границы; нужно `i < 5`.
- Бесконечный цикл: счётчик не меняется, а условие остаётся истинным.
- Лишняя точка с запятой после `for` может создать цикл с пустым телом.

### 6. Функции и область видимости

Функции позволяют разделять программу на небольшие повторно используемые
части.

**Python**

``` python
def square(x):
    return x * x

print(square(5))
```

**C**

``` c
#include <stdio.h>

int square(int x) {
    return x * x;
}

int main(void) {
    printf("%d\n", square(5));
    return 0;
}
```

В `int square(int x)` первый `int` — тип результата, `square` — имя
функции, а `int x` — параметр.

Если функция ничего не возвращает, используется `void`:

``` c
void print_line(void) {
    printf("-------------\n");
}
```

Функцию можно определить до места вызова или объявить прототипом:

``` c
int square(int x);

int main(void) {
    return square(5);
}

int square(int x) {
    return x * x;
}
```

#### Область видимости

``` c
int main(void) {
    int x = 10;

    if (x > 0) {
        int y = 20;
        printf("%d\n", y);
    }

    // printf("%d\n", y); // Ошибка: y вне области видимости
    return 0;
}
```

`y` доступна только внутри блока, в котором объявлена, и вложенных
блоков. В Python обычные блоки `if` и `for` не создают отдельную область
видимости для переменных так, как это делают блоки C.

#### Передача аргументов

Обычные параметры C передаются по значению — функция получает копию:

``` c
void change(int x) {
    x = 100;
}
```

Вызов `change(a)` не изменит исходную переменную `a`. Передача адреса
позволяет работать с исходным объектом, но подробно указатели
рассматриваются на следующем занятии.

### Практика 2. Условия и классификация — 20 минут

#### Задание 2.1. Знак и чётность

Считать целое число. Вывести `Positive`, `Negative` или `Zero`, а затем
`Even` или `Odd`.

``` c
#include <stdio.h>

int main(void) {
    int n;

    if (scanf("%d", &n) != 1) {
        printf("Invalid input\n");
        return 1;
    }

    if (n > 0) {
        printf("Positive\n");
    } else if (n < 0) {
        printf("Negative\n");
    } else {
        printf("Zero\n");
    }

    if (n % 2 == 0) {
        printf("Even\n");
    } else {
        printf("Odd\n");
    }

    return 0;
}
```

Тесты: `0` → Zero и Even; `-4` → Negative и Even; `7` → Positive и Odd.

#### Задание 2.2. Максимум из трёх чисел

Считать `a`, `b`, `c` и вывести наибольшее число.

``` c
#include <stdio.h>

int main(void) {
    int a, b, c;
    int max;

    if (scanf("%d %d %d", &a, &b, &c) != 3) {
        printf("Invalid input\n");
        return 1;
    }

    max = a;

    if (b > max) {
        max = b;
    }

    if (c > max) {
        max = c;
    }

    printf("Maximum: %d\n", max);
    return 0;
}
```

Алгоритм: сначала считаем максимумом первое число, затем сравниваем с
ним второе и третье, обновляя значение при необходимости.

#### Задание 2.3. Классификация баллов

Ввести баллы от 0 до 100 и вывести категорию:

- 90–100 — отлично;
- 70–89 — хорошо;
- 50–69 — удовлетворительно;
- 0–49 — неудовлетворительно.

Числа вне диапазона считать некорректными.

``` c
#include <stdio.h>

int main(void) {
    int score;

    if (scanf("%d", &score) != 1) {
        printf("Invalid input\n");
        return 1;
    }

    if (score < 0 || score > 100) {
        printf("Invalid score\n");
    } else if (score >= 90) {
        printf("Excellent\n");
    } else if (score >= 70) {
        printf("Good\n");
    } else if (score >= 50) {
        printf("Satisfactory\n");
    } else {
        printf("Unsatisfactory\n");
    }

    return 0;
}
```

Проверьте граничные значения: `49`, `50`, `69`, `70`, `89`, `90`.

### Практика 3. Числовые алгоритмы — 20 минут

#### Задание 3.1. Сумма от 1 до N

Считать положительное `N` и вычислить сумму `1 + 2 + ... + N`.

``` c
#include <stdio.h>

int main(void) {
    int n;
    int total = 0;

    if (scanf("%d", &n) != 1 || n < 1) {
        printf("Invalid input\n");
        return 1;
    }

    for (int i = 1; i <= n; i++) {
        total += i;
    }

    printf("%d\n", total);
    return 0;
}
```

Для `N = 5` результат — `15`. Переменная `total` — накопитель: на каждой
итерации к ней прибавляется очередное число.

**Дополнительный вопрос:** как изменить алгоритм, чтобы суммировать
только чётные числа?

#### Задание 3.2. Количество цифр

Считать неотрицательное целое число и посчитать цифры. Число `0`
содержит одну цифру.

``` c
#include <stdio.h>

int main(void) {
    int n;
    int count = 0;

    if (scanf("%d", &n) != 1 || n < 0) {
        printf("Invalid input\n");
        return 1;
    }

    do {
        count++;
        n /= 10;
    } while (n > 0);

    printf("%d\n", count);
    return 0;
}
```

Примеры: `0` → `1`; `7` → `1`; `42` → `2`; `1000` → `4`.

`do...while` нужен потому, что тело цикла должно выполниться хотя бы
один раз, в том числе для `n = 0`.

#### Задание 3.3. Факториал — дополнительное

Факториал `N` — произведение целых чисел от 1 до `N`, причём `0! = 1`.

``` c
#include <stdio.h>

int main(void) {
    int n;
    unsigned long long result = 1;

    if (scanf("%d", &n) != 1 || n < 0 || n > 20) {
        printf("Invalid input\n");
        return 1;
    }

    for (int i = 1; i <= n; i++) {
        result *= (unsigned long long)i;
    }

    printf("%llu\n", result);
    return 0;
}
```

Диапазон ограничен значением 20, чтобы результат помещался в
`unsigned long long` на обычных современных реализациях. Если группа
отстаёт, оставьте факториал для самостоятельной работы.

### Практика 4. Массивы — 15 минут

Массив C хранит элементы одного типа и имеет фиксированное число
элементов:

``` c
int numbers[5] = {4, 8, 2, 9, 1};
```

Индексы — от `0` до `4`. Обращение к `numbers[5]` выходит за границы и
приводит к неопределённому поведению.

В Python список может динамически увеличиваться:

``` python
numbers = [4, 8, 2, 9, 1]
print(max(numbers))
```

#### Задание 4.1. Найти минимум и максимум

``` c
#include <stdio.h>

int main(void) {
    int numbers[5] = {4, 8, 2, 9, 1};
    int min = numbers[0];
    int max = numbers[0];

    for (int i = 1; i < 5; i++) {
        if (numbers[i] < min) {
            min = numbers[i];
        }

        if (numbers[i] > max) {
            max = numbers[i];
        }
    }

    printf("Min: %d\n", min);
    printf("Max: %d\n", max);
    return 0;
}
```

Результат:

``` text
Min: 1
Max: 9
```

Алгоритм:

1.  Первый элемент используется как начальные минимум и максимум.
2.  Цикл проходит по оставшимся элементам.
3.  При необходимости обновляются минимум и максимум.
4.  После цикла выводятся найденные значения.

#### Задание 4.2. Расширение

Добавьте подсчёт суммы, среднего арифметического и количества чётных
элементов.

``` c
int sum = 0;
int even_count = 0;

for (int i = 0; i < 5; i++) {
    sum += numbers[i];

    if (numbers[i] % 2 == 0) {
        even_count++;
    }
}

double average = (double)sum / 5;
```

Приведение к `double` позволяет избежать целочисленного деления.

Вопрос: почему нельзя всегда получить длину массива C так же, как через
`len(numbers)` в Python? При передаче массива в функцию он обычно
преобразуется в указатель на первый элемент, поэтому размер часто
передают отдельным аргументом.

## Итоги и типичные ошибки

### Итоги

- C обычно компилируют и собирают перед запуском.
- Тип переменной влияет на операции и представление данных.
- `if`, `for`, `while` реализуют знакомые по Python алгоритмы, но имеют
  другой синтаксис.
- Функции помогают разделять программу на логические части.
- Массивы имеют фиксированный размер; индексация начинается с нуля.
- Ошибки компиляции, выполнения и логики нужно различать.

### Типичные ошибки

| Ошибка                       | Причина                                            | Что проверить                       |
