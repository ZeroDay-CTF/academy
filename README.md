
Общая база знаний и учебная программа CTF-команды.
## Принципы
- Здесь хранятся только материалы, которые можно публиковать в этом репозитории.
- Персональные оценки, данные кандидатов, секреты и закрытые флаги не добавляются.
- Учебные лабораторные и тесты хранятся в репозитории `labs`; здесь размещаются конспекты и ссылки на них.
- Перед публикацией разборов CTF проверьте правила соревнования и разрешение на публикацию.

## Идентификаторы
- Урок: `REV-01`, `WEB-01`, `CRYPTO-01`, `TRAFFIC-01`.
- Лабораторная: `REV-LAB-01`.
- Домашняя работа: `REV-HW-01`.
- Разбор CTF: `CTF-YYYY-NAME`.

Замените ссылки `ORG` в заметках на фактическое имя вашей GitHub Organization.
