# Шаблоны

Создавайте новые заметки на основе шаблонов:
- `Урок.md`
- `Практика.md`
- `Разбор CTF.md`
- `Ретроспектива.md`

При необходимости подключите встроенный плагин Templates в Obsidian и укажите `Templates` как папку шаблонов. Поля даты в шаблонах пока текстовые; их можно заменить на переменные встроенного плагина или другого проверенного решения.
