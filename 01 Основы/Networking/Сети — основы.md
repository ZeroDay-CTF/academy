# Сети — основы

## Цель
Понимать базовые сетевые понятия, необходимые для анализа трафика и веб-задач.

## Темы
- IP-адрес и порт
- TCP и UDP
- DNS
- HTTP и HTTPS
- Клиент и сервер
- Запрос и ответ
- Базовая диагностика: `ping`, `curl`, `dig`, `ss`

## Практика
- [ ] Получить заголовки HTTP-ответа через `curl -I`.
- [ ] Посмотреть DNS-записи учебного домена, на который есть разрешение.
- [ ] Объяснить, почему IP-адрес и порт — разные вещи.
