# Linux — основы

## Цель
Уверенно работать в терминале и понимать файловую систему Linux.

## Минимум, который нужно освоить
- Навигация: `pwd`, `ls`, `cd`
- Файлы и каталоги: `cat`, `less`, `cp`, `mv`, `mkdir`, `rm`
- Поиск: `find`, `grep`
- Права: `chmod`, `chown`, `id`
- Процессы: `ps`, `top`, `kill`
- Потоки и перенаправление: `>`, `>>`, `<`, `|`
- Справка: `man`, `--help`

## Практика
- [ ] Создать каталог для лабораторной и организовать файлы.
- [ ] Найти файл по имени и строку внутри набора текстовых файлов.
- [ ] Объяснить разницу между stdout и stderr.
- [ ] Посмотреть права файла и объяснить их значение.
